Sprint 2 - fluxo 2: Consulta de Estoque Geral: No caso ConsultarEstoqueGeral, o método listar() virou um método “faz-tudo”: listar() -> busca dados -> cria mapas auxiliares -> define chave de agrupamento -> agrega quantidades -> monta linhas de resposta -> enriquece com produto/localização -> ordena -> calcula totais -> retorna DTO final demonstrando uma baixa coesão interna. -> A consulta apresenta acoplamento funcional moderado porque o caso de uso depende simultaneamente de estoque, produtos e localizações para montar uma visão consolidada. Essa dependência é justificável para a funcionalidade, mas o método listar() concentra também a lógica de junção, enriquecimento e formatação dos dados. Assim, mudanças em Produto, Localização ou na regra de consolidação tendem a impactar diretamente esse caso de uso. Uma alternativa seria decompor em um consulta geral e um consolidador do estoque geral.
